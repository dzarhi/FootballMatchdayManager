# לוח משחקים - מ.ס. אשדוד, ילדים ב'

אתר קטן ורספונסיבי (מחשב + טלפון) המציג לאוהדים ולהורים את משחקי הקבוצה: יום, תאריך,
שעה, שם המגרש וכפתור ניווט ישיר בוויז לכתובת המגרש.

זהו אתר **סטטי** (HTML/CSS/JS בלבד, ללא שרת/בסיס נתונים), כך שאפשר לארח אותו בחינם ב-GitHub Pages.

## מבנה הפרויקט

```
index.html          # העמוד הציבורי - לוח המשחקים
admin.html          # עמוד ניהול לעריכת המשחקים (לא לשיתוף פומבי!)
css/style.css        # עיצוב כללי, RTL ורספונסיבי
css/admin.css        # עיצוב טבלת הניהול
js/utils.js          # פונקציות עזר (תאריכים, קישור וויז, טעינת נתונים)
js/app.js            # לוגיקת התצוגה הציבורית
js/admin.js          # לוגיקת עמוד הניהול
data/matches.json    # קובץ הנתונים - כאן נמצאים כל המשחקים
```

## הרצה מקומית

אין צורך בהתקנות. אפשר לפתוח שרת סטטי פשוט מהתיקייה, לדוגמה עם Python:

```powershell
python -m http.server 8000
```

ואז לפתוח בדפדפן: http://localhost:8000

(פתיחה ישירה של `index.html` בכפול-קליק לרוב לא תעבוד בגלל חסימת `fetch` לקבצים מקומיים - `file://`.)

## עדכון המשחקים

הנתונים לדוגמה בקובץ `data/matches.json` הם **placeholder** - יש להחליף אותם בנתונים האמיתיים
(יריבות, תאריכים, שעות וכתובות מדויקות של המגרשים).

יש שתי דרכים לעדכן:

1. **עריכה ידנית** - פתחו את `data/matches.json` בכל עורך טקסט ועדכנו את הערכים לפי הפורמט הקיים.
2. **דרך עמוד הניהול** (`admin.html`) - טופס/טבלה נוחים להוספה, עריכה ומחיקה של משחקים.
   שימו לב: מכיוון שהאתר סטטי (אין שרת), השינויים בעמוד הניהול נשמרים רק בדפדפן שלכם
   (localStorage). כדי שהעדכון יופיע לכל הצופים באתר החי:
   1. ערכו/הוסיפו משחקים בעמוד הניהול.
   2. לחצו "הורד קובץ מעודכן (JSON)".
   3. החליפו את הקובץ שהורד בקובץ `data/matches.json` בפרויקט.
   4. בצעו `git commit` + `git push` כדי לעדכן את האתר החי.

   עמוד הניהול אינו מוגן בסיסמה אמיתית (זה לא אפשרי באתר סטטי בלי שרת) - לכן אל תשתפו
   את הקישור אליו בפומבי, אלא רק בין מי שמעדכן את התוכן.

### פורמט רשומת משחק

```json
{
  "id": "מזהה ייחודי כלשהו",
  "opponent": "שם הקבוצה היריבה",
  "homeAway": "home או away",
  "date": "YYYY-MM-DD",
  "time": "HH:MM",
  "result": "תוצאה סופית, לדוגמה 3-1 (אופציונלי, למשחקים שכבר היו)",
  "venueName": "שם המגרש",
  "address": "כתובת מדויקת - משמשת לקישור הניווט בוויז",
  "notes": "הערה חופשית (אופציונלי)"
}
```

היום בשבוע מחושב אוטומטית מתוך התאריך, ואין צורך להזין אותו בנפרד.
שדה ה-`result` מוצג רק במשחקים שכבר היו (לפי התאריך) ורק אם הוזן.

## פרסום ב-GitHub Pages

1. צרו repository חדש ב-GitHub והעלו אליו את כל קבצי הפרויקט (`git init`, `git add .`,
   `git commit`, `git remote add origin ...`, `git push`).
2. בעמוד ה-repository ב-GitHub: **Settings → Pages**.
3. תחת "Build and deployment" בחרו **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`.
4. שמרו - לאחר דקה-שתיים האתר יהיה זמין בכתובת מהסוג
   `https://<username>.github.io/<repo-name>/`.
5. לכל עדכון נתונים: עדכנו את `data/matches.json`, בצעו commit + push, וה-Pages יתעדכן אוטומטית.

## התאמות עיצוב

- הצבעים (אדום וזהב - צבעי מ.ס. אשדוד הרשמיים) מוגדרים כמשתני CSS בראש הקובץ
  [css/style.css](css/style.css) (`--primary`, `--accent`, `--dark` וכו') - אפשר לשנות אותם בקלות.
- שם הקבוצה וכותרות מופיעים ישירות ב-[index.html](index.html) וב-[admin.html](admin.html).

## סמל הקבוצה (לוגו)

הקובץ [assets/logo.png](assets/logo.png) הוא סמל הקבוצה המוצג באתר. כדי להחליף אותו בסמל אחר:

1. שימו קובץ תמונה (PNG/SVG) בתיקיית `assets/`, לדוגמה `assets/logo.png`.
2. עדכנו את שורת ה-`<img src="assets/logo.png" ...>` בקבצי [index.html](index.html) ו-
   [admin.html](admin.html) כך שתצביע לקובץ החדש.
